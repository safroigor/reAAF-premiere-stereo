# reAAF Premiere Stereo

Неофициальное расширение REAPER для открытия AAF-проектов, в том числе AAF из
Adobe Premiere Pro со встроенным аудиоматериалом.

Актуальная проверенная версия: **0.3.7-premiere-stereo.5**

## Возможности

- открытие AAF через **File → Open Project** в REAPER;
- автоматическое извлечение встроенного аудио;
- восстановление подтверждённых пар Premiere Breakout-to-Mono `_L` / `_R` в
  стерео без перекодирования;
- сохранение тайминга, исходных смещений, уровня клипов, фейдов, автоматизации,
  частоты дискретизации и разрядности;
- поддержка Unicode-путей, включая папки и имена на кириллице;
- безопасное сохранение неоднозначных пар в виде отдельных моно-дорожек.

## Установка в Windows

1. Закройте REAPER.
2. Скопируйте `reaper_reAAF.dll` в `%APPDATA%\REAPER\UserPlugins`.
3. Запустите REAPER заново.
4. Выберите **File → Open Project** и откройте файл `.aaf`.
5. После проверки сохраните проект в формате `.rpp`.

При импорте встроенного аудио рядом с AAF создаётся папка
`<имя AAF>-media`. Не удаляйте и не перемещайте её отдельно от сохранённого
проекта REAPER.

## Ограничения

- Стерео собирается только для надёжно распознанных соседних пар `_L` / `_R`.
- Плагины, MIDI, маршрутизация, темп и часть автоматизации обычно не входят в
  AAF и поэтому не могут быть восстановлены.
- Embedded AAF из Premiere размером около 2 ГБ может оказаться повреждённым.
  Для больших проектов используйте **Separate Audio**, уменьшайте объём через
  **Trim Audio Files** либо делите монтаж на несколько AAF.
- Перенос маркеров зависит от экспортера и для Premiere не гарантируется.
